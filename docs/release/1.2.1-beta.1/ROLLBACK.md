# 备份、切换与回退

1. 更新前导出书架备份，从托盘正常退出程序，保留当前安装包。
2. 稳定用户在设置中选择测试通道后再检查更新。测试版与稳定版共用原安装入口及已经选择的物理书架，不需重新导入。
3. 旧 Beta 1 若仍有独立书架，两份资料不会自动合并，也不会静默复制凭据。
4. 回退时正常退出测试版，在设置选择稳定通道并使用提供的确认流程；或运行此前官方 1.2.0 安装包。保留书架和用户确认，不清空或直接覆盖 Profile。
5. 安装中断时保留资料，重新运行已核对校验值的安装包；不要随意补 DLL 或关闭防护。

本次不变更主库或人工确认 schema。旧版不展示新影像/阅读入口的情况不等于资料丢失；重新安装支持版本可恢复展示。书架导出与更新器快照用途不同，加密凭据仍绑定当前 Windows 用户，不能当作跨电脑账号备份。
