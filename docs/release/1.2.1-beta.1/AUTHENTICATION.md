# 账号与隐私

NextMoe 账号、API Key、匿名目录访问是不同的访问方式。已登录账号不需要额外填写 API Key。个人同步与登录独立，默认关闭；只有用户明确启用的同步方向才可写云端。

Bangumi 授权用于其允许访问的资料及关联。401 提示授权失效；403 提示本次访问被拒绝；超时、离线、429 与服务端故障不会自动删除已保存授权。音乐、AniList 和 NDL 的公开资料读取不借用 NextMoe 或 Bangumi 凭据。

凭据继续由当前 Windows 用户保护。不要将 Profile、DPAPI 文件、Cookie 或 Token 上传到 GitHub Issues 或聊天群。需要日志时先删除私人路径、账号标识及其他不宜公开的内容。

本轮自动化账号验证使用合成凭据与本地协议替身，匿名真实接口验证独立记录。不把合成测试解释为真人 OAuth 到期恢复已验收。
