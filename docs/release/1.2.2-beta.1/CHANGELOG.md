# The Order 1.2.2-beta.1 · Beta

## 本次更新

- 新增统计分区，展示游玩时长、活动趋势与作品状态。
- 支持五种管理器的已验证备份格式导入和兼容 ZIP 导出，保留原生备份。
- 改进作品核验与进度合并；时长可相加，并保留可靠的日期和会话。
- 支持为此前相加的记录补全来源日期，避免重复累计。
- 包含 1.2.1 的媒体入口与硬盘兼容改进。

## 安装与回退

安装前从托盘正常退出 The Order，并在「设置 → 备份与恢复」导出书架备份。升级保留当前书架；卸载不删除游戏文件或个人资料。

需要回退时，使用兼容的旧版安装包；如果已使用 Beta 的新迁移资料，请先在 Beta 恢复升级前的备份，再切换旧版。不要直接复制两个 Profile 文件夹。

## 已知限制

- 测试版的迁移资料采用较新的扩展格式。切回 1.2.1 前，请在 Beta 中恢复升级前的书架备份；恢复会回到备份时点，请先另存当前资料。
- 迁移已验证固定版本的公开格式和合成资料，尚不能代表所有真实用户备份。未知、损坏或缺少作品类型证据的记录会提示或排除。
- 兼容导出受目标管理器的精度和字段限制，不能代替 The Order 原生备份。ReinaManager 恢复需从 ZIP 解出数据库。
- 面向 Windows 10 1809 / Windows 11 x64；Windows 10 干净实机、全部 DPI 和长期稳定性尚未全面验证，安装包暂未签名。
- 已有真实 exFAT 合成目录验证；FAT32、ReFS 实盘和反馈用户设备仍未覆盖。
- 外部资料和视频受网络、平台权限、地区及订阅条件影响；收录链接不保证当前可播放或购买。
