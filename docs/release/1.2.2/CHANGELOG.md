# The Order 1.2.2

## 本次更新

- 新增统计分区，展示游玩趋势、活动分布与作品状态。
- 支持五种管理器备份 ZIP 导入与兼容导出，改进进度合并、时长相加及可靠日期保留。
- 整理设置分类与页面布局，精简操作按钮文字。
- 修复部分显示模式下的详情图片、加载失败留白和文字排版问题。

本版将 1.2.2 beta 2 转为正式发布，保留已有媒体入口和硬盘兼容修复。

## 安装与兼容性

安装前从托盘退出 The Order。升级保留当前书架与个人资料，1.2.2 Beta 可直接升级。旧正式版用户也会通过正式通道收到本次更新。

本版使用 NativeExtras v7。回退至 1.2.1 或更早版本前，请先恢复兼容的早期备份；勿强制转换较新的资料格式。

## 验证范围

完整测试、安装与升级通道结果见随附 VALIDATION.md。Windows 10 干净实机、全部 DPI、真实迁移及长期稳定性尚未全面验收。
