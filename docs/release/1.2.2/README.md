# The Order 1.2.2

Windows x64 正式版，包含 1.2.2 beta 2 已完成的功能与修复。安装包附带运行依赖，无需开发 SDK；游戏宣传影像无需用户申请 Twitch 账号或 API Key。部分资料源仍需自行授权。

安装前从托盘退出 The Order，并在「设置 → 备份与迁移」导出书架备份。升级保留当前书架，1.2.2 Beta 用户可以直接升级正式版。

本版与 1.2.2 Beta 使用相同的 NativeExtras v7。回退到 1.2.1 或更早版本前，须先恢复兼容的早期备份，不可让旧版强写较新的资料格式。不要直接复制 Profile 文件夹。

校验和、验证范围及边界见发布页及随附 VALIDATION.md；完整备份请使用程序原生书架备份。
