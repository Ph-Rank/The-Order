# 连接与资料授权

在「对话 → 连接与授权 → OpenAI」中可通过系统浏览器登录 ChatGPT。使用 ChatGPT 额度需要在登录时授权，额度和可用模型取决于账号权限。也可在同一入口手动切换到 API Key，按 OpenAI API 计费。其他模型服务商通过各自的 API Key 连接。

登录凭据和 API Key 由 Windows 在本机保护。切换连接不会扩大书架、历史聊天、记忆或联网搜索的授权范围。这些权限可在程序中单独调整。

作品资料平台独立授权。在设置中启用个人同步后，程序可以把状态和评分写入已连接且完成作品关联的平台。遇到未完成的作品，可在同步结果中核对站点编号。
