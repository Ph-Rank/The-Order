# The Order 1.3.0

1.3.0 将 1.3.0-beta.2 的游戏内攻略、本地文件阅读与可选 AI 对话带到稳定通道。从 1.2.2 升级后可继续使用已有书架。

## 游戏内攻略与文件阅读

- 通过 The Order 启动游戏后，默认按 **J** 呼出或收起助手。可在设置中更换快捷键。
- 网络攻略可以按路线查看流程图、存档分支和详细步骤。流程图支持拖动、缩放和点击阅读。
- 可以为作品添加本地攻略和说明文件。内置阅读器支持 TXT、PDF、Word、图片和 Excel。Word 读取正文与表格，Excel 读取已经保存的单元格结果。
- 修复部分攻略章节无法读取的问题，包括《CLANNAD》和《魔女的夜宴》。

## 可选 AI 对话

- 左侧「对话」支持已适配的 OpenAI、Google、Anthropic、xAI 和 DeepSeek 接口。请自行配置 API 密钥。可用型号与费用取决于服务商和账户权限。
- 每个会话可单独选择模型和对话预设。书架记录、历史聊天、偏好记忆及联网搜索分别授权。
- 支持图片附件、流式回复、停止生成和查看引用。费用区分服务商返回值、估算值与未知值。

## 界面与兼容性

- 改进作品详情、音乐列表和小窗口阅读布局。
- 修复 Windows 关闭动画效果时的启动问题。动画不可用时使用静态启动界面。

## 安装与更新

下载 **The-Order-1.3.0-Setup-x64.exe**，适用于 Windows 10 1809 及以上和 Windows 11 的 x64 系统。安装包暂未签名。升级前请导出书架备份，从系统托盘退出 The Order。

也可在程序设置中选择「稳定」通道检查更新。安装包、完整源码、更新通道文件和校验和随本版提供。实际验证范围见附件 VALIDATION.md。
