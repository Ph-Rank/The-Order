# The Order 1.3.0

下载 **[The-Order-1.3.0-Setup-x64.exe](https://github.com/Ph-Rank/The-Order/releases/download/v1.3.0/The-Order-1.3.0-Setup-x64.exe)**。安装前从系统托盘退出 The Order，并在设置中导出书架备份。升级后继续使用所选书架。程序内更新使用「稳定」通道。

用 The Order 启动游戏后，按 **J** 打开攻略助手。网络攻略提供流程图和连续阅读，也可以添加本地攻略和说明文件。「对话」需要自行配置服务商 API 密钥。
