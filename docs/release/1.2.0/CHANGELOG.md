# 1.2.0 更新说明

ACGN 专业资料与跨媒体浏览由公开测试进入正式版。

手动关联体验：同类候选可以核对资料差异后明确确认；跨媒体、系列/卷册、不同发行版使用独立的相关作品关系。无法读取的有效链接可以待核验保存，取得数据不会自动提升为确认。原有自动识别和跨站身份防线保留。

资料与状态：保留本地名称、封面、笔记和已读取资料；封面失败可独立重试。NextMoe 书架与设置页使用一致的访问状态，不再要求已登录账号额外填写 API Key。Bangumi 403 拒绝访问与真正的 401 授权失效分开处理，超时、限流和服务故障保留凭据并允许重试。

延续 Beta 的多语言资料、动画 PV/观看入口、音乐发行版与制作资料、书籍出版资料、全局启动设置与可靠性改进。

尚未包含后续音乐收听入口开发成果。
