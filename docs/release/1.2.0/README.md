# The Order 1.2.0

Windows x64 原生 Galgame 书架与 ACGN 跨媒体资料浏览。

从官方 [GitHub Release](https://github.com/Ph-Rank/The-Order/releases/tag/v1.2.0) 下载 `The-Order-1.2.0-Setup-x64.exe`，退出托盘中的 The Order 后安装。运行依赖随包提供，无需开发 SDK 或 Node.js。

## 本次更新

- 从本地游戏继续浏览动画、音乐、漫画、轻小说及出版资料。
- 动画支持角色、日语声优、制作人员、分集资料、PV 与已收录的正版观看入口。
- 音乐区分专辑组与具体发行版，展示多碟曲目、录音、音乐作品及制作资料。
- 漫画及小说保留系列、单卷、出版记录的区别，可查看作者、插画师、出版信息及已取得的 ISBN。
- 资料语言优先采用来源已有的中文译文，缺失时按偏好回退；不要求安装翻译模型。
- 手动对应可以核对标题、日期等差异后确认；媒体或层级不同的候选可添加为独立相关作品，读取失败的明确链接可保存为待核验选择。
- 人工确认、排除、相关作品及待核验选择独立于远程缓存保存，支持更换、撤销或恢复自动选择。
- 全局 LE、Magpie、后台静音默认关闭；游戏可继承或分别覆盖。

## 账号、数据及通道

目录访问支持匿名、NextMoe 账号与可选 API Key，按实际访问方式提示。Bangumi 账号独立连接。临时网络失败不代表凭据失效，也不清空本地书架。

正式版与 Beta 2 以后沿用统一安装入口和现有的物理书架选择机制。切换通道不会静默复制、合并或重建两份 Profile，也不会导出凭据。旧 Beta 1 的独立书架仍由首次启动选择是否继续使用；选择前保留原目录。已有两份独立书架不会自动合并，请勿直接复制 Profile 文件夹。

更新前先导出书架备份。设置中的更新安装流程还会保存受管的升级快照。卸载程序保留用户资料和游戏文件。回退说明见 [ROLLBACK.md](ROLLBACK.md)。

## 边界与反馈

当前没有漫画逐章目录、阅读器、VGMdb 或离线机器翻译包，也没有音乐订阅播放或收听入口补全。数据、封面和平台链接取决于来源覆盖及权限；平台页面存在不代表当前账号、地区或订阅可以播放。

实际验收环境为本轮可用的 Windows 11 x64；未取得干净 Windows 10、所有物理输入/DPI 组合或长期稳定性验收。安装包暂未签名，请核对官方来源及 SHA-256。详见 [HUMAN-CHECKS.md](HUMAN-CHECKS.md)。

遇到问题请提交 [GitHub Issue](https://github.com/Ph-Rank/The-Order/issues/new/choose)，写明版本、Windows 版本和复现步骤。不要上传 Token、凭据、完整 Profile 或未脱敏的私人路径。也可加入 [Telegram 交流群](https://t.me/+ONE-Lif0uZBiNzJh)。

资料来源与软件依赖许可分别保留；作品图片与资料不归入本项目源码许可。NextMoe、Bangumi、AniList、MusicBrainz、NDL Search 等来源署名随功能呈现。
