# 备份、切换与回退

1. 更新前导出书架备份，从托盘正常退出 The Order；保留当前安装包。
2. 1.1.2 稳定版可在设置检查 1.2.0 更新，Beta 2–4 用户可切换稳定通道。安装完成继续使用当前选择的书架，不需要重新导入游戏。
3. 旧 Beta 1 仍有独立资料时，首次启动提供继续使用哪份书架的明确选择。另一份书架不会被删除或自动合并，也不会自动复制凭据。
4. 需要回退时，退出 1.2.0，运行官方旧安装包。旧 1.1.2 能力范围较少；新 ACGN 用户链接仍保留在资料目录中，旧版本不展示它们，重新安装 1.2.0 后恢复。不要直接覆盖或清空 Profile。
5. 若安装中断或清单不完整，保留资料，重新运行同一已核验安装包修复；不要从不明位置补 DLL，也不要关闭系统防护。

升级快照与书架导出有不同的范围：书架备份用于本地库恢复，受管更新快照用于原物理资料目录的恢复。凭据依然受 Windows 用户保护，不能将一台电脑的加密文件当作可移植账号备份。

本轮的可执行回退证据以隔离 Test 资料和独立实验安装身份为范围；真实日用安装与 Production 未被切换。
