# The Order 1.3.1-beta.1

本次测试版带来日用版的后续改进。设为 Beta 通道后，可以从 1.3.0 检查更新。

## 游戏内助手

- 窗口和无边框模式下，助手按显示器像素绘制。低分辨率游戏中的文字与流程图更清晰，较小窗口会缩减工具栏占用。
- 网络攻略初次打开显示「全部路线」。切换时列出路线名称。同一次游玩内重新呼出，会继续显示之前的路线、页面和位置。
- 游戏打开退出确认等原生弹窗时，助手暂时隐藏。取消退出后可以继续阅读。
- 游戏内可切换到「对话」。刷新模型时会读取服务商目录，并识别新增的对话模型系列。

## 发现、书架与统计

- 发现的搜索、发售月历、评分榜和资讯保留已载入的结果与筛选。切换栏目可接着浏览，手动刷新时重新读取。
- 修复部分 KunGal 作品封面无法显示，以及切回书架时「继续游玩」封面显示延迟的问题。
- 页面加载使用 The Order 徽记，改进关联作品跳转和页底栏目折叠的动效。统计的「每周节奏」使用更明亮的半透明柱形。

## 设置、帮助与状态

- 「设置 → 资料与维护 → 使用帮助」新增离线指南，配有带编号的《9-nine-》示例图，覆盖游戏导入、攻略、统计、对话和备份。
- 左侧「状态」集中显示后台任务和运行消息。未读报错或需要操作时显示提示点。
- 设置按类别排列。「更新与反馈」可以检查更新、切换通道并提交问题或建议。

## 安装与更新

下载 **The-Order-1.3.1-beta.1-Setup-x64.exe**，适用于 Windows 10 1809 及以上和 Windows 11 的 x64 系统。安装包暂未签名。升级前请导出书架备份，从系统托盘退出 The Order。实际验证范围见附件 VALIDATION.md。
