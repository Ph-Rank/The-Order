# The Order 1.3.1-beta.2

本次 Beta 修复保存游戏启动设置后反复核对失败的问题，并汇总近期的资料同步、批量评分和统计图改进。

## 修复启动位置确认失败

- 修复 [#2](https://github.com/Ph-Rank/The-Order/issues/2)：保存“游戏文件与启动”设置后，立即更新详情页中的启动核验状态，避免继续提交过期快照。
- 核验期间若安装设置或文件已变化，会重新读取当前位置供再次确认，不再反复使用同一份旧记录。权限问题会显示对应提示。
- 保留文件身份、工作目录和启动设置检查；不会自动放行已变化的程序，也不需要删除本机核验记录。

## 个人评分与游玩状态

- NextMoe OAuth 登录统一申请所需授权，移除重复的个人数据同步面板。
- 评分读入改为在 NextMoe 设置中手动点击；保存个人状态或评分后，同步写入已授权且已关联的 NextMoe、番组计划和 VNDB。
- 设置提供一键写入各平台；批量修改新增个人评分，保存后同样执行同步。
- 修复番组计划写入时的 HTTP 415，并补全 VNDB 同步反馈和关联读取。
- “查看未完成作品”中可直接输入站点作品 ID，核对后绑定并重试。NextMoe 明确公布条目合并且目标可确认时，自动更新关联并重试；有冲突或目标不明确时保留手动选择。
- 改进同步失败原因、未完成作品列表和重复通知清理。

## 游玩统计

- 游玩趋势可切换“时长”和“游玩时段”。时段图按作品使用不同颜色，纵轴根据实际记录选择合适区间，支持跨午夜显示。
- 悬停即时显示当前色块的游戏和起止时间，突出当前色块并淡化其他色块；移除下方图例。
- 统计页移除缺少可归属日期时长的说明文字，保留原始记录和累计时长。

## 游戏内对话与界面

- 改进游戏内助手的 Markdown 显示、模型列表筛选及小窗口按钮布局。
- 精简 OpenAI、Gemini 模型选择中的无关型号，并兼容已有会话的模型选择。
- 空白游戏内聊天不再保存为会话；整理使用帮助入口和标题栏显示。

## 安装与更新

下载 **The-Order-1.3.1-beta.2-Setup-x64.exe**，或在设置中选择 Beta 通道检查更新。支持 Windows 10 1809 及以上和 Windows 11 x64；安装包暂未签名。

升级前建议导出书架备份，并正常退出 The Order。回退旧版应先另存当前资料，避免旧版无法识别新增的关联数据。实际测试、未验证范围和文件校验见附件 **VALIDATION.md**、**SOURCE-MANIFEST.json**、**SHA256SUMS.txt**。
