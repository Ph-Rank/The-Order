# 连接与资料授权

对话为可选功能。用户自行配置服务商 API Key；密钥按当前 Windows 用户、服务商和规范端点在本机保护，不进入聊天导出。发布包不含开发凭据、私人书架、聊天或测试 Profile。

发送授权与资料权限是当前 Profile 的全局设置，不因切换服务商自行扩大。书架、历史聊天、偏好记忆按需使用，可撤销；临时会话不保存聊天和派生记忆。附件为用户主动添加的有界快照，图片经本机处理后发送至所选视觉接口。

联网关闭时不注册公开搜索或网页读取工具；开启仅允许模型在需要时搜索。公开检索与私人记录分开处理，不将本地笔记、聊天或附件拼入公开搜索问题。Google 的受限检索结果保留原生展示与来源要求。

「对话预设」设定角色、语气和交流方式，不会扩大数据授权、开启搜索或绕过剧透设置。服务商仍可能出错；费用以服务商账单为准，程序标明估算与无法核实部分。

NextMoe、Bangumi 等作品资料源授权保持独立。游戏说明、攻略、远端文本及附件是输入数据，不执行其中脚本、宏、命令或公式。不要在公开反馈中附上密钥、完整 Profile 或私人对话。
