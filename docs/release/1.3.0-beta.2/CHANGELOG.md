# The Order 1.3.0-beta.2

本次 Beta 提供游戏内攻略、本地文件阅读和可选 AI 对话，并包含近期交互与兼容性修复。稳定通道继续提供 1.2.2；主动选择 Beta 可更新至本版。

**Windows 10 1809 / Windows 11 · x64**。运行依赖已包含，安装包暂未签名。下载 `The-Order-1.3.0-beta.2-Setup-x64.exe`；升级前请先导出备份。

## 游戏攻略与只读阅读

- 接入网络攻略，可浏览路线流程图、存档分支及详细步骤，隐藏仅用于回收的路线。
- 为通过 The Order 启动的游戏准备攻略覆盖层，默认 J 呼出或收起，支持自定义快捷键。
- 支持网络攻略与手动添加的本地攻略；没有网络攻略时可使用本地资料。攻略与说明文件在同一阅读窗口切换，恢复上次页面和阅读位置。
- 内置 TXT、PDF、Word、图片和 Excel 只读阅读。Word 显示提取的正文与表格，Excel 显示已保存的单元格结果，不执行宏、公式或文档脚本；不承诺还原所有复杂文档排版。
- 流程图支持滚轮缩放、拖动平移与点击阅读，区分存档、选项和主次结局；改进连接线、路线顺序、文字完整性及窗口外释放拖动。

## 可选的 AI 对话

- 新增「对话」工作台，支持 OpenAI、Google、Anthropic、xAI 和 DeepSeek 的已适配接口；可用型号由用户连接权限和接口能力决定。
- 每个会话独立保存模型、思考等级与对话预设；全局资料授权、联网权限、剧透限制和可管理的偏好记忆分别控制。
- 可在授权范围内查询本地记录、历史聊天及偏好；累计时长排名由程序对完整书架排序，不以最近游玩切片代替。
- 支持手动文字及图片附件、流式回复、停止生成与来源查看。费用显示区分实际返回、估算和未知。
- 引用按首次出现从1编号，同组升序、去重，紧凑显示；修复模型厂商切换时弹窗变化和列表反复重建。

## 界面与交互

- 整理游戏工具、攻略与说明文件布局，减少低频资料对主阅读区的占用。
- 移除作品横幅中过多的标签文字，改进音乐滚动及部分展开、切换和小窗口交互。
- 对话页同时适配深色与浅色，两侧栏按可用宽度挤压正文，不覆盖输入区。

## 其他修复

- 修复部分作品的网络攻略读取失败问题，包括《CLANNAD》《魔女的夜宴》。此前已下载本版安装包的用户，可重新下载本页安装包。

## 其他修复

- 修复关闭 Windows 动画效果时无法启动的问题；页面动画不可用时使用静态显示。
- 延续攻略章节兼容修正，支持《CLANNAD》《魔女的夜宴》等资料中的章节标题。

## 兼容与限制

Beta 与稳定通道分开。升级保留所选书架；回退前另存当前资料并使用兼容备份，勿让旧版强写新字段。游玩时长不等于路线完成进度，AI 回复及剧透过滤仍可能出错。

尚未完成全部真实游戏/独占全屏、干净 Windows 10、全部 DPI 和长期稳定性验收。无本地机器翻译功能。实际验证范围见 `VALIDATION.md`。
