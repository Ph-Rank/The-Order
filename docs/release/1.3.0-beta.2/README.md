# The Order 1.3.0-beta.2

Windows x64 公开测试版。本次带来游戏内攻略、本地文件阅读器与可选的 AI「对话」工作台，并改进详情、音乐滚动及阅读交互。

下载 `The-Order-1.3.0-beta.2-Setup-x64.exe`。安装前从系统托盘退出 The Order，并在「设置 → 备份与迁移」导出备份。升级沿用现有书架；不必重新扫描游戏。已安装版本也可在「设置 → 程序更新」选择 Beta 通道检查更新。稳定通道仍为 1.2.2。

游戏通过 The Order 启动后，默认按 J 显示或收起攻略；快捷键可自定义。本地攻略和说明文件由用户手动添加，阅读器只读。覆盖层的实际兼容性取决于游戏、渲染后端和启动权限，并非所有独占全屏游戏均已逐一验证。

「对话」需要用户自行配置 API Key，并按需授权书架记录、聊天和偏好记忆。未配置时不发送模型请求。联网搜索可以关闭；开启只提供搜索权限。模型费用由服务商收取，程序费用显示可能是估算。

本版不包含本地 7B 机器翻译，也不下载模型权重。运行依赖随包提供；流程图使用系统 WebView2。

安装包尚未代码签名。校验文件为 `SHA256SUMS.txt`；验证范围见 `VALIDATION.md`。反馈：[GitHub Issues](https://github.com/Ph-Rank/The-Order/issues) · [Telegram](https://t.me/+ONE-Lif0uZBiNzJh)。请勿上传密钥、完整个人资料目录或未经脱敏的日志。
