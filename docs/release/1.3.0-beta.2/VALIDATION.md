# The Order 1.3.0-beta.2 验证范围

## 本次启动修复

2026-11-03，修复前以全新独立 Test Profile 复现与 Issue #1 一致的 StopAnimation("Translation") 参数异常和启动失败提示。首次无动画策略应用时，该属性尚未注册。修复仅管理可选页面动画的注册、复位和异常回退，并更正通用启动失败提示；没有变更书架或 Profile 数据格式、依赖和原生攻略协议。

开发候选 Release WinUI 构建零警告/错误，41 项启动/材质定向回归通过。三个实际原生 Test 实例分别覆盖无动画冷启动、运行中关闭/恢复动画、开始动画后抛错的静态回退；书架、统计和设置导航成功，静态不透明度为 1，位移为零（或从未注册），三个实例均以退出码 0 正常退出。非动画启动错误仍进入失败保护。

无动画状态由 Test 专用策略开关在首次策略应用前注入，调用实际生产分支；未改 Windows 系统设置。实窗观察覆盖 200% 缩放、1147×802 DIP 的书架和设置，不能当作报告者 150% 缩放或真实系统开关操作的复测。

公开构建、安装包、最终原生入口及更新校验的结果随附件 VALIDATION.md 补充；构建或打包本身不构成验收通过。
