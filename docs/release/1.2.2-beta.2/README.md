# The Order 1.2.2-beta.2

Windows x64 公开测试版。安装包包含运行依赖，无需开发 SDK、Twitch 账号或 API Key 即可使用已部署的游戏影像服务；部分资料源仍需要用户自行授权。

安装前从托盘正常退出 The Order，并在「设置 → 备份与迁移」导出书架备份。升级保留当前书架；卸载不删除游戏文件或个人资料。

需要回退时，使用兼容的旧版安装包；如果已使用 Beta 的新迁移资料，请先在 Beta 恢复升级前的备份，再切换旧版。不要直接复制两个 Profile 文件夹。

本版为实验性质的预发布版本，仅主动选择 Beta 通道的用户接收。

版本、校验和、详细限制及反馈方式见同目录 CHANGELOG.md 和发布页。完整还原本软件请使用原生书架备份。
