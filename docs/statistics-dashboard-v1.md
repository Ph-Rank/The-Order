# 游玩统计 v1

## 产品与参考

独立侧栏「统计」，用于回顾本地书架的游玩时间和当前进度。采用现有 WinUI 视觉语言：少量概览卡片、一个主要趋势、分布和排行、按需展开的明细；图表使用原生向量，不增加图表依赖或 WebView。

参考 [Playnite 书架统计](https://api.playnite.link/docs/manual/features/gameLibraryStatistics.html) 的时长/完成状态分工、[GameActivity](https://github.com/Lacro59/playnite-gameactivity-plugin) 的时间趋势与单游戏记录，以及 [GOG GALAXY](https://www.gog.com/galaxy) 的游玩时长与书架概览。参考的是信息组织，不复制其代码或图片。没有采集成就、硬件监控或外部平台未提供的游玩行为。

## 已实现

- 累计时长、当前区间时长、活跃天数和游玩作品四项概览。
- 近7天、近30天、今年、全部记录，以及单作品筛选。
- 折线趋势按区间自动选择日、周、月或年，长历史按多年分组，避免无限图点。坐标根据秒/分/时取整刻度，安静日期补零，负修正保持符号。
- 区间游戏时长前8名横条，可进入作品详情；返回保留当前区间、作品筛选和统计上下文。其他作品可由顶部筛选查看。
- 当前书架状态环形图，显示完成数量与各状态数量。该图是当前状态快照，不是选定区间的通关率，也不按时长猜测完成。
- 星期一至日的区间累计时长柱图。
- 按需展开的逐日明细，每次30条，可继续加载及进入作品；统计说明和估算标注独立展开。
- 浅/深主题、宽窄窗口适配、原生焦点与键盘菜单；每个趋势值有可聚焦数值入口，逐日表作为数据替代。

## 数据口径

复用 `PlaytimeStatistics` 的本地记录和可撤回修正台账，只做只读投影。多个安装不重复计为多部游戏，同名不同ID不合并。个人名称保持原样。

累计包含现有有效时长；没有可归属日期的旧累计单独显示，不按最近游玩日期捏造历史。当前区间、趋势、排行、星期和日均均基于可归日记录。活跃日为净时长大于零的本地日期，游玩作品为区间净时长大于零的书架ID，日均分母为活跃日。

未完成或进行中的会话不猜测归日。跨日记录复用现有按经过时间分摊的估算，并说明没有完整暂停区间。人工修正保留正负；撤回不再计入。日期在今天之后的记录不进入截至今天的区间，仍可在说明中识别。当前书架状态不随日期筛选变化，单作品筛选会收窄状态图范围。

后台计算支持取消、世代校验和失败保留。旧任务即使忽略取消也不能覆盖新筛选；离开或退出不恢复旧结果。刷新和页面切换不改写库、会话或人工台账。没有新增Profile schema、用户数据迁移、网络请求、服务或遥测。
