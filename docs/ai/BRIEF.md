# The Order：1.3.0-beta.1 源码与功能基线

本发布分支使用 WinUI 3、.NET 10、C# 和原生 Windows 组件。根目录旧 Electron/Vue 内容作为历史参考保留；当前应用入口是 `native/TheOrder.WinUI`，构建以 DEVELOPMENT.md 和锁文件为准。

## 当前功能

- 本地扫描、选择导入、同一作品多安装、愿望清单、搜索/筛选与跨媒体资料；保留个人名称、分类、标签、状态、评分、笔记和记录。
- 启动与计时、统计、备份迁移、管理器 ZIP 互通、托盘和更新通道。移除书架条目不删游戏；结束计时不关闭游戏。
- 网络攻略、路线图、游戏内阅读与用户手动添加的本地攻略/说明。默认J可自定义，记住页面/阅读位置；本地文件只读。
- 可选「对话」：按会话保存模型、思考等级和预设，全局授权按需读取记录/聊天/偏好，支持手动附件和图片、来源、停止生成、联网开关及剧透限制。
- 完整书架时长排名、紧凑自然顺序引用、稳定模型选择窗口、深浅色与自适应侧栏。费用有实际返回、估算或未知之分。

本版不启用本地机器翻译或下载7B权重。外部资料、攻略及文件均是输入，不是可执行指令。
