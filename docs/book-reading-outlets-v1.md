# 漫画与小说阅读／购买入口 v1

2026-10-18；维护分支 `codex/book-outlets-v1-20261018`。基于 `9147b06` 及接手时全部未提交音乐增量开发。当前目录在 `update-channels-20261016/The-Order`；根仓库旧 Electron 工作和其他工作树不作为开发入口。本功能提交只包含书籍增量，音乐原修改继续留在工作区；最终运行载荷包含两者，以冻结清单识别。

## 已实现

已确认的漫画、轻小说及其他 Bangumi Book 详情新增“阅读与购买”。已有资料先显示，展开后才补读缺少的原始外链字段与漫画补充来源。卡片显示平台、用途、来源所标语言；有卷册、出版物或版本差异时补充说明。普通系列卡片省略重复的“系列入口”，详细来源、读取时间及排除原因放在“资料与来源”。只有真实存在的类别才显示；空结果为“暂未收录阅读或购买入口”。失败、取消与空结果分别处理。

没有新增阅读器、正文/章节下载、追更、购物、支付、平台登录、凭据申请、收费服务、服务器或自建索引。本轮无版本升级、公开发布、日用安装替换或 Production 操作。

## 来源与接入取舍

- **AniList**：既有详情查询原本已经请求 `externalLinks`，过去仅转成动画观看数据。现在为 Manga/NOVEL 原样保留 `id/site/url/type/language/notes/isDisabled`，按页面语义分类。`INFO` 既可能是出版社选卷/商品页，也可能只是百科，不能统一收进或排除。来源字段定义见 [MediaExternalLink](https://docs.anilist.co/reference/object/mediaexternallink)。`language` 描述站点内容语言，不保证当前 ISBN 译本语言或地区可用性。原书籍身份和多语言字段不变。
- **Bangumi**：复用当前书籍 infobox 的显式官方、连载、试读、电子/纸质购买、出版社网址；没有网址的出版社名称或 ISBN 不会变成猜测链接。原始字段和原 Book ID/层级保留。
- **NDL**：当前书目/出版记录继续属于资料来源。本轮两项真实请求分别限流和超时，未取得可证实的商品增量；不从 ISBN 造 Kindle、BOOK☆WALKER 或其他商品编号。
- **MangaDex：已接入受限的只读外链补充**。使用[当前公开 API schema](https://api.mangadex.org/docs/static/api.yaml)中的漫画元数据与 `links/officialLinks`，不访问上传章节、feed、图像或正文。仅已确认的 AniList MANGA/ONE_SHOT 可触发一次原题检索，最多 10 条；总数大于已返回条数即拒绝采用，不翻页建立反向索引。要求唯一 `links.al` 等于当前 AniList ID、至少一个完整标题一致，已知双方 MAL 编号也必须一致。无编号、重复编号、标题或其他编号冲突均不采用。标题只用于检索和反证，不能单独确认身份。

MangaDex schema 将链接公开为字符串字典，未逐项定义 `al/mal/bw` 短键。`al/mal` 的实际用法已由真实多作品 API 数据与现有 AniList ID/MAL ID 交叉验证，并有冻结反例测试；这是一条有范围限制的上游编号声明，不写入人工确认，不作为全站唯一性或独立版权认证。只保留来源实际返回的完整网址；例如 `bw: series/135012` 不会被展开成推测商品地址。MangaDex 网页验收被浏览器安全策略拦截，未绕过；本轮 MangaDex 证据是 API 元数据而非网页截图。限流遵循[官方限制说明](https://api.mangadex.org/docs/2-limitations/)，独立队列复用现有请求协调器实现，间隔至少 2.1 秒，20 秒操作超时，不无限重试。

没有接入 MangaUpdates、Google Books、Amazon 等独立 API。已经提供的准确 Amazon/Google Play Books 等网址可正常展示。

## 链接与身份规则

- 阅读／连载、试读、电子书、纸质书、其他官方用途、资料来源分别分类。站点首页、搜索、社交、禁用和跳转地址不作为入口。
- 已知平台的对应作品页、选卷/章节页保留；纯宣传介绍页默认归资料。未知平台不因其名字像书店就提升为购买入口。
- 没有显式试读证据不生成试读按钮。Amazon ASIN、纸质 ISBN 不证明电子版；格式未知的商品采用中性标签。
- AniList/Bangumi/NDL 普通资料页属于来源。MangaDex 自身上传记录不成为“正版阅读”。链接由源站收录不等于已逐条确认授权、下架与当前地区可读状态。
- 外链记录保留来源实体、格式、原始类型/备注/语言、时间；MangaDex 附加原声明的跨站编号。作品、系列、卷册、出版版本不被融合。
- 单卷不借用根 AniList 系列身份；只有系列入口时文案为“前往本系列”，没有“购买当前卷”的假承诺。有明确卷号、合订本、ISBN 差异会标注。没有相同 ISBN 证据时不称当前出版版本的准确商品。
- 内容语言不作为地区过滤。JP/TW/US 等仅是已知商店站点，未知不标成全球可用，其他语言入口保留。
- 去重保留决定卷册、版本、语言、ISBN 的参数和片段；未知 `tag` 参数也保留。相同资源的无语言副本可合并到唯一已知语言卡片，原证据保留；明确不同语言/版本不合并。
- 点击始终使用来源原网址，不新增或改写返佣参数。复用 HTTPS、公网域名、默认端口、无账号信息等外链规则。仅用户点击后交给系统安全启动器；不在后台探测任意平台，不处理支付或登录。

## 缓存、状态与兼容

新增字段均是可丢弃远程元数据；`HasBookLinkMetadata/HasExternalLinkMetadata` 识别旧缓存，首次展开只刷新固定源 ID。MangaDex 补充使用现有 AniList 远程缓存的独立 `booklinks:md-v1:<format>:<id>` 键，复用 24 小时新鲜期、14 天最大离线期、容量淘汰、Profile 封装、原子写入和世代保护。不建设第二套用户数据持久化；旧版无法识别新缓存行时可忽略，原用户确认与主库无需迁移。

已有人工确认/拒绝/更换/撤销继续由 Native Profile 用户身份组件持久保存，独立于所有远程缓存。MangaDex 只产生带证据的元数据声明，不新增自动确认记录。查询失败保留有效旧资料，错误返回的新编号不替换旧入口。切书、切卷、取消、折叠、退出后，迟到响应不能污染新页面或继续发出旧源补查。
