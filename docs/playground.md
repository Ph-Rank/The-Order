# 对话工作台

这是可选讨论空间，不是启动游戏的前置条件。用户在「连接与授权」配置自己的服务商Key并决定全局权限。按需读取书架、历史聊天和偏好记忆；临时会话不持久化聊天和派生记忆。

模型、低/中/高思考和「对话预设」按会话独立保存。预设决定角色、语气与交流方式，优先于内置默认风格，不能扩大权限或创造事实。模型列表由连接目录筛选各系列新版；目录可用不证明账户额度、视觉或高级字段均可用。

联网关闭时不提供公开搜索/网页读取；开启只是放开权限。公开资料检索与私人上下文分开。限制剧透打开时，以书架中可靠身份和当前「玩过」状态为依据放行细节，其他作品仅概括讨论；关闭时不施加这层剧情限制。自然语言语义边界仍可能判断有误。

累计游玩排名由宿主对完整书架有效时长排序，包括有效人工记录；最近游玩列表不是全库排名。时长与完成进度、喜好分别处理。

来源保留原始身份，显示引用按每条回答首次出现编号；同源沿用原号，同组升序去重，分别可点击。未知来源不变成核验链接。用户消息不展示来源入口，回复不显示「助手」前缀。

文字和图片附件由用户手动添加，按有界快照发送，不自动扫描游戏目录。Word/Excel/PDF作为游戏资料阅读与「对话」上传是不同功能；对话图片支持不意味着PDF附件已经接入。

费用逐请求记录；有接口金额时使用接口值，否则根据已核实单价和用量估算。旧汇总或缺失字段只能部分估算；未知型号不虚构价格。费用以服务商账单为准。

取消、超时和权限变化阻止后续接纳，不自动重发付费请求。已发送给服务商的资料不能由本机撤销。真实模型质量、账户支持与搜索覆盖随服务商变化；验证范围见发布说明。
