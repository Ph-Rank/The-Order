# 对话验证范围

当前公开版本为1.3.0-beta.1。具体发布产物、测试结果和限制以 `docs/release/1.3.0-beta.1/VALIDATION.md` 为准。

验证分为：授权/持久化/工具/排序/协议的自动回归；独立Test Profile的原生窗口检查；已有日用版本的深浅色、窄窗、引用及侧栏观察；历史真实服务商接口调试。这些证据不能互相替代。

OpenAI、Google与DeepSeek曾有受限预算真实调试；没有将未测试的Claude/xAI账号写成真实调用通过，也不将单次对话扩展为型号智力或幻觉率排行榜。本次发布不包含测试Key、私人聊天或它们的原始输出。

重点保护权限撤回、临时会话、遗忘、工作身份、在途取消、来源范围、图片附件边界、旧用量兼容、完整书架排名及每会话设置。模型默认风格服从用户预设，授权与剧情边界独立生效。

尚未验收所有模型与额度、真实网络故障组合、全部DPI/输入设备、大历史长期性能、所有Windows版本和所有游戏覆盖层兼容性。程序或单元测试通过不构成这些能力的保证。
