# 快速上手

## 从这里开始

把电脑里已有的游戏加入 **书架**，以后从这里启动。游玩时长、攻略和个人笔记都能在同一部作品下找到。

### 第一次使用

1. 在 **书架** 点 **导入游戏**，选一个已解压、可以运行的游戏文件夹。
2. 勾选扫描到的游戏，点 **加入书架**。完成后点 **查看书架**。
3. 打开作品封面，点 **启动游戏**。若需要确认启动位置，选平时用来打开游戏的文件。

![《9-nine-》第 1～4 章的书架主页。编号 ① 标出导入游戏，② 标出继续游戏。](images/shelf.png)

*图 1 · ① 导入游戏，② 继续游戏。*

### 按要做的事查找

| 要做的事 | 对应章节 |
| --- | --- |
| 一次导入多部游戏，或改正认错的版本 | [导入与识别](#导入与识别) |
| 边玩边看攻略、PDF 或补丁说明 | [攻略与游戏内助手](#攻略与游戏内助手) |
| 核对游玩时长和统计 | [启动与计时](#启动与计时) · [游玩统计](#游玩统计) |
| 换电脑，或把旧管理器里的记录迁过来 | [备份与换机](#备份与换机) |

帮助随程序提供，离线也能读。搜索目录、补全资料和读取网络攻略需要联网。

## 导入与识别

### 添加已有的游戏

1. 打开 **书架 → 导入游戏 → 选择游戏文件夹**。导入单部游戏时，选它自己的文件夹。批量导入时，选包含多个游戏子文件夹的上一级目录。
2. 扫描完成后，核对作品名称和路径，勾选想添加的条目。也可先点 **全选可导入游戏**，再去掉不需要的作品。
3. 点 **加入书架**。游戏仍留在原目录。重复扫描时，已添加的安装会被标出。

![导入页。编号 ① 标出选择游戏文件夹，② 标出从 Steam 或游戏库发现。](images/import.png)

*图 2 · ① 扫描指定目录，② 管理经常扫描的游戏库。*

### 从常用文件夹或 Steam 找游戏

1. 在导入页打开 **从 Steam / 游戏库发现**。也可以从 **设置 → 书架与识别 → 自动发现游戏（文件夹 / Steam）** 进入。
2. 用 **添加游戏库文件夹** 选择存放游戏的目录。添加 Steam 库时，选包含 `steamapps` 的文件夹。
3. 点 **检查新游戏**，再点 **选择要导入的游戏**。以后发现新游戏时，打开左侧 **状态 → 运行消息**，点 **选择要导入的游戏**。

### 找对作品和版本

- **封面或简介缺失**时，在 **设置 → 书架与识别** 点 **补全缺失资料**。
- **认成另一部作品**时，在该作品详情的 **…** 菜单点 **重新识别**。多部作品可以在书架勾选后点 **识别所选**。
- **出现「待核对」时**，点 **查看候选详情**，比较原名、发行日期和版本。原版、重制版和附篇名称相近，选定前最好核对发行信息。
- **知道正确的作品**时，在 **发现** 找到它并复制目录编号，或复制 KunGal 作品链接。回到 **待核对**，选中对应的本地游戏，在 **手动关联** 中粘贴，核对后点 **确认手动关联**。

## 启动与计时

![《9-nine-》第 3 章的作品详情顶部。编号 ① 标出启动游戏，② 标出启动设置，③ 标出右上角更多菜单。](images/details.png)

*图 3 · ① 启动游戏，② 调整启动设置，③ 找到游戏文件与游玩记录。*

### 选对启动位置

1. 从书架打开作品详情，点 **启动游戏**。在书架右键封面也能启动。
2. 若出现 **确认启动位置**，核对文件名和路径。优先选你平时用来打开游戏的启动文件。
3. 游戏搬家后，点详情页 **… → 游戏文件与启动**。在原安装上点 **修改路径与启动设置**，更新游戏文件夹和启动文件并保存。沿用同一个书架条目可以保留游玩记录。

同一作品有多个版本时，可用 **关联游戏文件夹** 添加安装，再用 **设为默认启动** 选常玩的版本。如果只想临时换一个版本，从详情页的 **… → 本次启动哪个文件夹的游戏** 中选择。

### 核对或补记时长

从书架启动游戏会自动计时。退出游戏后，在作品详情的 **… → 游玩记录、攻略与补充资料 → 游玩记录** 核对记录。

> 单次游玩满 **5 分钟**才计入时长和次数。

- **暂停或恢复计时** · 右键单击系统托盘里的 The Order 图标，选择 **暂停计时** 或 **恢复计时**。计时遇到错误时，在左侧 **状态** 查看消息。
- **忘了从书架启动** · 在 **游玩记录** 展开 **补记或修正时长**，选日期、方式并填入小时数。要增加当天的时长，选 **补记时长**。要设定当天的总量，选 **将当天时长修正为**。填好后点 **保存时长**。
- **补记填错了** · 在对应条目下点 **撤回这条修正**。

# 日常使用

## 整理书架

### 从书架里找游戏

| 操作 | 用途 |
| --- | --- |
| **搜索** | 查找已经入库的作品。要找新的作品，到左侧 **发现**。 |
| **筛选** | 按状态、收藏或条目类型缩小范围，例如只看想玩或缺资料的游戏。 |
| **排序** | 按最近游玩等顺序排列。旁边两个视图按钮可在封面网格和列表间切换。 |
| **继续游玩** | 从书架顶部继续玩最近的作品，也可以先打开它的详情。 |

### 为作品补上自己的信息

1. 在书架右键封面选 **编辑**，或进入详情后点 **编辑**。
2. 按需填写个人名称、状态、评分、分类、标签和笔记，或调整收藏。
3. 想一次整理多部作品时，在书架点 **选择**，勾选后点 **批量编辑**。在 **个人评分** 填一个分数，可同时给所选作品打分。留空时保留各自的评分。

详情页的 **…** 菜单提供封面和横幅的选择。自选图片后也可恢复自动选择。**从书架移除**会移除这条书架记录，磁盘里的游戏文件仍在原处。

### 同步游玩状态与评分

在 **设置 → 资料与账号** 连接 NextMoe、番组计划或 VNDB。连接 VNDB 时，在网站创建带 **列表写入（listwrite）** 权限的令牌，再粘贴到 The Order，点 **保存并验证**。

- **保存时同步** · 单部或批量编辑保存后，将本次改动的状态和评分写入已关联的已连接网站。
- **写入整份书架** · 在 **资料与账号** 点 **一键写入各平台**，提交书架中已关联作品的现有状态与评分。
- **指定网站** · 在作品详情点 **… → 同步状态与评分**，勾选目标网站后点 **确认同步**。
- **读入 NextMoe 评分** · 在 **资料与账号 → NextMoe** 点 **一键读入评分**，作品详情会单独显示读入的云端评分。

各站的结果可在左侧 **状态** 查看。评分按网站的精度取整。状态未设置、评分留空或填了 0 分时，对应的网站记录会保留。同步到 NextMoe 的评分会公开显示。

## 发现与关联作品

![发现页顶部。编号 ① 指向搜索、发售月历、评分榜和资讯入口，② 指向作品搜索框。](images/discovery.png)

*图 4 · ① 切换栏目，② 按名称、编号或作品链接查找。*

- **搜索** · 可以输入作品名、`#编号` 或支持的作品链接。结果太多时试试原名，或加上版本名。未安装的作品可以 **加入愿望单**，以后再关联游戏文件夹。
- **发售月历** · 用左右箭头换月。日期右上角的数字是当天收录的作品数。点日期看当天，点 **全部日期** 恢复整月列表，点 **本月** 回到当前月份。
- **评分榜** · 切换评分来源，或用 **筛选** 限定最低票数、发行年份等条件。例如想找近期作品，可以同时设发行年份和最低票数，减少低票高分的结果。
- **Galgame 资讯** · 按栏目和来源浏览，点 **阅读原文** 前往来源网站。滚动到列表末尾会继续加载。

### 看原声、动画、书籍和宣传片

从作品详情进入 **关联作品**，再选 **游戏**、**动画**、**音乐** 或 **书籍**。例如想找原声，进入 **音乐**，点专辑看发行版和曲目。可浏览的条目取决于目录收录。

有宣传片的作品会提供 **宣传影像 / PV**。展开后可以用 **播放** 或页面提供的外部入口。音乐详情有收听入口时，也可按页面提供的渠道打开。

## 攻略与游戏内助手

### 找到攻略或添加本地文件

打开作品详情的 **… → 游玩记录、攻略与补充资料**。

![《9-nine-》第 3 章的作品工具窗口。编号 ① 指向网络攻略，② 指向本地攻略，③ 指向说明文件，④ 指向本地攻略页的文件按钮。](images/game-tools.png)

*图 5 · ① 网络攻略，② 本地攻略，③ 说明文件。④ 用于添加或管理当前栏目里的文件。*

| 要看的内容 | 打开方法 |
| --- | --- |
| 在线路线与选项 | **网络攻略 → 读取攻略**。有多份时，按来源和适用版本选择。 |
| 自己保存的攻略 | **本地攻略 → 文件 → 添加攻略文件**。 |
| README、补丁说明和注释 | **说明文件 → 文件 → 添加说明／注释文件**。 |

在 **流程图** 中点节点或「几个选项」查看步骤，用滚轮缩放、按住左键拖动。只想看主路线时，可勾选 **隐藏回收路线**。要从头顺读，切到 **连续阅读**，再选路线。

本地阅读器可只读打开常见文本、PDF、Word、Excel 和图片。看 PDF 时，点页码跳转，或用两旁的箭头翻页。用键盘阅读时，可按 `←`、`→` 翻页。滚轮只滚动当前页。重新打开同一个文件会恢复阅读位置。移动了文件时，需要重新选择它。

### 游玩时呼出助手

1. 从书架启动游戏。切到游戏窗口后按 `J` 打开，再按一次收起。
2. 每次启动游戏后，网络攻略从「全部路线」的总路线图开始。点路线名称可以查看该路线。游戏仍在运行时，按快捷键收起再打开会回到刚才的页面。顶部可切换攻略、说明文件和对话。
3. 默认先用网络攻略。缺少网络攻略时，会使用你添加的本地攻略。要让某部作品优先看本地攻略，在它的 **游戏内助手** 页将来源改为 **本地攻略**，点 **保存攻略来源**。

若 `J` 无反应，先看作品的 **游戏内助手 → 本次助手状态**。快捷键可在 **设置 → 游玩 → 游戏内助手** 更改。点击当前按键录入新键，检查占用后保存。全屏时无法打开，可以试试窗口或无边框模式。

## 游玩统计

![筛选到《9-nine-》第 3 章的游玩统计页。编号 ① 标出统计区间，② 标出作品筛选。](images/statistics.png)

*图 6 · ① 选时间，② 选作品。悬停在趋势图上可查看对应日期的时长。*

### 从总量看到单日

1. 打开左侧 **统计**，选择日期范围。想只看某一部游戏，再从 **全部作品** 中选择它。
2. 看 **区间时长** 了解这段时间玩了多久。**累计游玩** 可以包含日期不明的旧时长，所以两者不一定相同。
3. 将鼠标移到 **游玩趋势** 查看对应日期，或移到 **每周节奏** 查看对应星期的合计。**游玩时长排行** 可在框内滚动，点作品进入详情。

**书架进度** 按你设置的「玩过」「在玩」「想玩」等状态计数。要核对某次游玩或修改某天的时长，可以回到作品的 [游玩记录](#启动与计时)。

## AI 对话

### 配置后发出第一条消息

1. 打开左侧 **对话**。入口隐藏时，到 **设置 → 常规 → 外观** 勾选 **显示对话入口**。
2. 在会话侧栏底部打开 **连接与授权**。选择 **OpenAI** 可在浏览器完成 **ChatGPT 登录**，也可手动选择 **API Key**。其他服务商填写从各自控制台获取的 API Key。勾选 **允许发送我主动提交的讨论内容** 后保存，发送框会显示当前 OpenAI 连接的用量来源。
3. 展开右侧 **运行设置**，点模型栏，选择当前 Key 可用的模型。新建会话后即可发送问题。输入框左下的 **＋** 可添加图片，使用前先确认模型支持图片。

![对话工作区。编号 ① 标出左下的连接与授权，② 标出右上角的运行设置。](images/chat.png)

*图 7 · ① 配置连接与授权，② 选择模型并调整当前会话。*

### 决定本轮可以用什么资料

- **联网搜索** · 开启后，支持的模型可按需查找公开网页。关闭后，消息仍会发给所选服务商。
- **使用已授权的记录与记忆** · 想问「我最近玩了哪些游戏」时，先在 **连接与授权** 允许读取本地游玩记录，再打开会话中的这项设置。与问题相关的授权资料可随请求发送。
- **限制剧透** · 开启时，仅对书架中标为「玩过」的游戏放行具体剧情细节。**对话预设** 可用来设置语气和回复风格，例如「先给结论，再解释理由」。

游戏内助手的 **对话** 也可以读取画面。需要问「屏幕上这句话出自哪里」时，打开 **读取画面** 再发送。当前游戏画面会随这条消息发给支持图片的模型。The Order 不把画面存入聊天记录。取不到画面时，可关掉这一项再发文字。

## 常用设置

| 我想调整…… | 去哪里找 |
| --- | --- |
| 浅色、深色、材质效果 | **常规 → 外观**。想减少材质效果时，可选 **标准**。 |

## 备份与换机

### 保存书架，再恢复到新电脑

![备份与存储中的书架备份区。编号 ① 标出导出书架备份，② 标出从备份恢复。](images/backup.png)

*图 8 · ① 导出现在的书架，② 选择备份并预览恢复内容。*

1. 打开 **设置 → 备份与存储 → 导出书架备份**，把备份文件存到便于找回的位置。
2. 换机时，把备份文件复制到新电脑。游戏文件、存档以及原本放在其他目录的攻略、自选图片等也要另行复制。
3. 在新电脑点 **从备份恢复**，选择备份文件。盘符或目录变化时，恢复后在作品的 **游戏文件与启动** 中更新位置。

> 只想找回遗漏的作品，选 **添加缺失条目**。选 **恢复整份书架** 会覆盖当前书架和个人记录。先核对预览，需要保留现状时先导出一份当前备份。

### 从其他管理器迁移

在原管理器导出备份 ZIP，再到 **备份与存储 → 从其他管理器导入 → 选择备份 ZIP**。可以选择 PotatoVN、Vnite、ReinaManager、Playnite 或 LunaBox 的备份。先检查预览中的新增和匹配结果，再确认导入。

### 清理可重新生成的缓存

打开 **设置 → 备份与存储 → 磁盘缓存**。可分别清理 **在线图片**、**缩略图**、**横幅与玻璃成品**。清理后，首次访问相关页面可能需要重新下载或生成。个人封面、游戏文件和游玩记录会保留。

## 更新与反馈

### 查看运行消息

左侧 **状态** 的圆点表示有未读消息。打开 **状态** 后，可以在 **后台任务** 查看扫描、识别和更新下载的进度，在 **运行消息** 查看通知、警告和报错。有后续操作的消息会提供对应按钮。消息记录保留到本次退出。

### 检查更新

打开 **设置 → 更新与反馈 → 检查更新**。日常使用选 **正式版（推荐）**，想体验测试功能可选 **Beta 公开测试**。有可用版本时，先看 **完整更新说明**，再按提示安装。

### 提交能复现的问题

1. 在 **更新与反馈** 点 **提交反馈**，选 **问题反馈** 或 **功能建议**。
2. 标题写清楚现象，例如「点启动游戏后仍提示选择启动文件」。正文按顺序写操作、预期结果和实际结果，再补一句是每次发生还是偶尔发生。
3. 点 **预览** 检查将公开的内容。按需选用诊断信息，提交前检查是否有私人路径、账号或密钥。
4. 如有程序内提交入口，按提示在浏览器授权 GitHub，回到 The Order 确认。也可以选网页提交。已提交的反馈可以从 **查看反馈** 找到。

## 常见问题

### 扫描不到已安装的游戏

先打开游戏文件夹，确认里面有可运行的游戏。只扫一部时直接选它的文件夹。扫描结果显示已入库时，清空书架的搜索和筛选再找。仍不确定可以回看 [导入与识别](#导入与识别)。

### 有作品资料，却没有网络攻略

目录和攻略各自收录。先确认当前关联的是正确的版本。没有可用攻略时，可在 [本地攻略](#攻略与游戏内助手) 中添加手头的文件。

### 之前能读的 PDF 或说明突然打不开

确认原文件仍在原位置。如果移动或重命名了，在 **本地攻略 → 文件** 用 **更换攻略文件** 重新选择。说明文件可以移除旧链接后再添加。

### 详情里的时长和统计不同

详情展示该作品的总时长，统计首页默认显示一个日期区间。先核对日期和作品筛选。如果差额来自没有日期的旧记录，可在 [游玩统计](#游玩统计) 对照累计时长，在作品的 **游玩记录** 中逐条核对。
