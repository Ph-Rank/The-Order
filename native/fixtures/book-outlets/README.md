# Book outlet regression excerpts

These are minimal factual projections of four bounded public MangaDex metadata responses: identifiers, titles and supplied links only. `provenance.json` records the original API URL, retrieval time and response hash. No synopsis, page, image or chapter content is included. The application does not use these as an identity index or hand-maintained link registry.

Tests use separate explicit synthetic mutations for missing identifiers, conflicts and truncated results. Those mutations are not presented as provider data. Third-party data and title rights remain with their respective owners; the application source license does not relicense external content.
